처음 시작하기

로그인 없이 시작할 수 있습니다. 새 YouTube 영상 분석은 하루 3개까지 무료이며 WordAhead Plus 연간 구독으로 분석 제한을 해제할 수 있습니다. 기존 자막·단어장 복습과 YouTube 재생은 구독 없이 이용할 수 있습니다. 홈의 예시 자막을 열고 단어를 누른 뒤 뜻·발음을 확인하고 + 버튼으로 저장하세요. “내 단어장”에서 복습하거나 삭제할 수 있습니다. “자막 직접 붙여넣기”에서는 직접 작성했거나 사용할 권한이 있는 영어 텍스트를 입력할 수 있습니다.

자막은 이 기기에만 저장되며 다른 사용자에게 공개되지 않습니다. YouTube 공식 플레이어로 영상을 재생할 수 있으며 재생목록 가져오기는 지원하지 않습니다. 핵심 학습 기능은 지역별로 구분하지 않지만 YouTube·Wiktionary 접근과 영어 음성 제공 여부는 지역 및 기기 설정에 따라 달라질 수 있습니다.

앱 하단 “학습 데이터 삭제”에서 전체 학습 기록을 삭제할 수 있습니다. “체크 어휘 백업”은 알고 있는 어휘만 보관하며 저장한 단어·자막 전체 백업은 아닙니다.

YouTube 영상 링크를 추가하고 목록 항목을 누르면 영어 자동 자막을 우선 가져와 전체 화면으로 표시합니다. 자동 자막이 없으면 제공되는 영어 자막을 사용합니다. 단어를 누르면 하단에 뜻·발음 기호·발음 듣기가 표시됩니다.

비공개, 연령 제한, 영어 자막 미제공 또는 접근 제한 영상은 자동 수집할 수 없습니다. 직접 자막을 붙여 넣어 학습할 수 있습니다. 예시 자막은 실제 YouTube 영상에서 수집한 내용이 아닌 데모입니다.

내장 사전은 위키낱말사전 공개 데이터를 사용합니다. 내장 한글 뜻이 없으면 온라인 한국어 위키낱말사전을 검색하고, 해당 뜻도 없으면 MyMemory 영한 번역을 시도합니다. 검증된 한글 뜻은 기기에 캐시하여 다시 사용할 수 있습니다. 인터넷 연결·번역 서비스 이용량 제한으로 한글 뜻을 가져오지 못하면 안내와 참고 영문 뜻을 표시합니다. 모든 단어의 발음 기호가 수록된 것은 아니며, 발음 듣기는 기기의 영어 음성 합성 기능을 사용합니다.

YouTube 자막을 열면 화면 위에 공식 YouTube 플레이어가 표시됩니다. ▶ 시간 버튼이나 문장의 빈 부분을 누르면 앱 안의 영상이 그 시점으로 이동합니다. 단어 자체를 누르면 하단 사전이 열립니다. 처음에는 플레이어의 재생 버튼을 눌러야 할 수 있습니다. 다른 화면으로 이동하거나 앱이 백그라운드로 가면 일시정지합니다. 예시 자막에는 영상이 표시되지 않습니다. 시간 정보가 없는 직접 입력 자막은 시점 이동을 지원하지 않습니다. 앱 내 재생이 제한된 영상은 YouTube 앱에서 열 수 있습니다.

YouTube API 서비스를 사용하며 이용 시 YouTube 서비스 약관이 적용됩니다. Google 개인정보처리방침도 확인해주세요.

구독과 오프라인 사용

설정에서 Apple 구독 구매·복원·관리를 할 수 있습니다. 신규 분석에 성공한 서로 다른 영상만 하루 한도에 포함됩니다. 실패한 분석과 이미 분석한 영상은 다시 차감하지 않습니다. 이용량은 기기별로 관리됩니다. YouTube 앱에 다운로드한 영상은 해당 앱에서만 오프라인 재생할 수 있습니다. WordAhead에 저장한 자막과 단어는 오프라인에서도 볼 수 있습니다.
