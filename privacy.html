기기에 저장하는 정보

영상 링크, 수집하거나 붙여 넣은 자막, 저장한 단어와 학습 상태·조회 기록은 기기의 앱 또는 브라우저 저장소에 보관합니다. 회원가입, 광고 SDK, 사용자 추적, 분석 SDK를 사용하지 않습니다. 운영자가 학습 기록을 수집하는 기능은 없습니다.

YouTube 자막과 외부 요청

영상을 열어 자막을 요청하면 영상 ID와 네트워크 요청 정보가 YouTube로 전송됩니다. 웹 버전에서는 Cloudflare 자막 서버를 거치고, iOS 앱에서는 기기에서 YouTube에 직접 요청합니다. 서버는 학습 기록이나 자막을 데이터베이스에 저장하지 않습니다. 서비스 제공 과정에서 YouTube·Cloudflare는 각 개인정보처리방침에 따라 IP 주소 등의 요청 정보를 처리할 수 있습니다.

온라인 상태에서 단어 뜻을 요청하면 검색 단어와 네트워크 요청 정보가 Wikimedia의 Wiktionary로 전송됩니다. 자막 전체나 개인 학습 기록은 전송하지 않습니다. 연결 실패 또는 오프라인에서는 내장 사전을 사용합니다. 맞춤 단어 추천은 알고 있는 단어, 뜻 조회와 학습 상태를 기기 안에서 분석하며 공식 어휘 수준 검사 결과는 아닙니다.

글꼴은 기기 글꼴을 사용합니다. 예시 이미지는 Unsplash, YouTube 썸네일은 YouTube에서 불러옵니다. 해당 서비스는 이미지·글꼴 요청에 포함된 네트워크 정보를 처리할 수 있습니다. 시스템 음성 합성에는 외부 사전·AI 서버를 사용하지 않습니다.

영한 뜻 번역과 영상 재생

내장·온라인 위키낱말사전에 한글 뜻이 없으면 검색 단어와 요청 정보를 MyMemory(Translated)의 영한 번역 API로 보냅니다. 자막 전체와 학습 기록은 전송하지 않습니다. 결과는 자동 번역으로, 네트워크·서비스 이용량 제한으로 제공되지 않을 수 있습니다. 유효한 한글 뜻은 최대 1,000개까지 기기에 캐시하며, 저장한 단어의 뜻은 기기에 보관합니다. MyMemory는 자체 개인정보처리 기준에 따라 요청 정보를 처리할 수 있습니다.

YouTube 자막을 열면 공식 임베드 플레이어를 불러옵니다. YouTube·Google은 영상 ID, 재생 시점, 앱 식별자와 IP 주소 등의 요청 정보를 처리하며 쿠키나 유사 기술 및 광고를 사용할 수 있습니다. 자막 전체와 개인 단어장은 플레이어에 전송하지 않습니다. 앱은 영상 파일을 다운로드하거나 음성을 분리하지 않습니다. YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

구독 및 분석 이용량

연간 구독 결제와 구매 복원은 Apple StoreKit이 처리합니다. 운영자는 카드 정보에 접근하지 않습니다. 구매 권한은 Apple이 검증한 거래 내역으로 확인합니다. 하루 새 영상 분석 이용량과 이미 분석한 영상 ID는 기기에 저장하며 기기 간 동기화하지 않습니다.

삭제와 보관

단어는 내 단어장에서 삭제할 수 있습니다. 전체 학습 기록은 앱 하단의 “학습 데이터 삭제”에서 삭제할 수 있습니다. 별도로 내보낸 백업 파일은 파일 앱에서 삭제해야 합니다. 앱 삭제 또는 브라우저 사이트 데이터 삭제로도 기기 저장 정보를 삭제할 수 있습니다. 운영체제의 백업 설정에 따라 기기 저장 정보가 백업될 수 있습니다.
