# WordAhead 심사 대응

이번 통지는 신규 개발자 계정에 대한 추가 정보 요청입니다. 버그가 특정되었다는 뜻은 아니지만, 아래 자료와 완성된 실제 빌드가 필요합니다.

## 직접 해야 할 일
1. 최신 정식 iOS가 설치된 실제 iPhone에 최종 제출 빌드를 설치합니다. 지원하는 iPhone 크기와 최소 지원 OS도 별도로 테스트합니다. iPhone 전용 설정이므로 iPad에서도 호환 실행을 확인하세요.
2. 앱 아이콘을 눌러 실행하는 장면부터 화면 녹화합니다. 예시 자막 → 단어 선택 → 뜻 → 발음 듣기 → 단어 저장 → 알고 있는 어휘 체크 → 맞춤 추천 → 내 단어장 복습·삭제 → 직접 자막 입력 → 백업 저장·불러오기 → 도움말·개인정보 → 전체 학습 데이터 삭제 순서로 보여주세요. 자동 수집이 출시 기능에 포함되면 권한 있는 영상으로 성공과 실패 후 직접 입력 경로도 보여주세요. 로그인·회원가입·계정 삭제·결제·공개 게시 기능은 현재 소스에 없습니다.
3. 네트워크 끊김, 영어 자막 없는 영상, 잘못된 링크, 발음, 재실행 후 저장 유지, 백업 취소·손상 파일, 작은 화면, 데이터 삭제 후 재실행을 확인합니다. 녹화 기기 모델·OS·앱 버전·빌드 번호와 결과를 기록합니다. 테스트하지 않은 항목을 통과했다고 쓰지 마세요.
4. 영문 답변의 대괄호를 실제 녹화 링크와 버전 정보로 교체합니다. 로그인 없이 접근 가능한 영상 링크를 다른 브라우저에서도 확인합니다. App Store Connect 심사 메시지에 답변하고 동일 내용을 App Review Information의 Notes에도 입력합니다. 영상은 첨부하거나 접근 가능한 링크를 사용합니다.
5. 소스 변경을 포함한 새 Archive를 만들고 빌드 번호를 증가시켜 업로드합니다. 현재 저장소는 1.0.0 (7)이지만 심사에 제출된 버전과 일치하는지는 확인이 필요합니다. Xcode 서명 팀과 Bundle ID를 확인하세요.
6. 실제 사용 화면으로 스크린샷을 교체하고 영상 재생·재생목록·항상 가능한 자동 자막·AI 기능처럼 구현되지 않았거나 보장할 수 없는 설명을 제거합니다. 지원/개인정보 웹 페이지도 배포하고 URL을 확인합니다.
7. YouTube 자동 자막 기능은 비공개 player API를 사용합니다. 권한·플랫폼 약관과 출시 지역별 작동을 확인하세요. 권한 근거를 제공할 수 없다면 이 기능을 제거하거나 허가된 방식으로 바꾼 뒤 새 빌드·메타데이터·답변에 함께 반영해야 합니다. 현재 이 기능을 임의로 제거하지는 않았습니다.
8. dictionary/NOTICE.md와 manifest.json을 라이선스 자료로 보관합니다. 사전의 원문·기여자·CC BY-SA 표기를 유지하세요. 자체 예시 글의 작성 권한과 Unsplash 이미지 사용 조건도 확인하세요. 의료·금융 등 규제 산업 기능은 소스에 없습니다.
9. App Privacy 답변을 실제 배포의 YouTube·Wikimedia·Cloudflare·Unsplash 요청 및 로그 정책에 맞춰 확인하세요. 회원가입이 없으므로 계정 삭제 기능을 새로 추가할 필요는 없습니다. 체크 어휘 백업 파일은 학습 데이터 삭제 후에도 별도 파일로 남습니다.

## 적용한 수정
- iOS에서 내부 도움말·개인정보·사전 안내 링크의 새 창 요청도 열도록 처리
- 서비스 워커가 실패한 JS/사전 요청에 HTML을 반환하던 처리 수정
- Google Fonts 외부 요청 제거, 기기 글꼴 사용
- 전체 학습 데이터 삭제와 취소 확인 창 추가
- 예시 데이터의 타 채널명 제거, 자동 수집 제한과 권한 있는 자막 입력 안내
- 현재 기능·배포 한계에 맞춘 README 및 심사 답변 작성

## 남은 확인
소스는 실제 제출 바이너리와 다를 수 있습니다. 물리 기기 QA·화면 녹화·서명 Archive·업로드·App Store Connect 입력 및 외부 서비스 권한 확인은 아직 완료되지 않았습니다.

## 이번 검증 결과
- JavaScript 문법 검사와 Swift 파싱 통과.
- iPhoneOS Release 빌드 통과 (CODE_SIGNING_ALLOWED=NO). 서명·Archive·App Store 업로드 검증은 포함하지 않습니다.
- 독립 Chrome 테스트에서 외부 네트워크를 차단하고 예시 자막 열기, 단어 조회·저장, 재실행 후 저장 유지, 전체 삭제 취소·실행, 도움말 이동을 확인했습니다. 페이지 오류는 발생하지 않았습니다.
- iOS WKWebView 런타임, 실제 영어 음성 출력, YouTube·Wiktionary 온라인 동작과 물리 기기 QA는 아직 미검증입니다.
