# WordAhead

영어 자막 읽기와 단어 학습을 위한 PWA 시제품입니다.

## 실행

정적 HTTP 서버로 프로젝트 폴더를 제공해 브라우저에서 엽니다. HTTPS 또는 localhost에서 서비스 워커를 사용할 수 있습니다.

## 현재 기능

- 샘플 자막 및 직접 붙여 넣은 영어 자막 읽기
- 단어 선택, 내장 사전 뜻풀이, 브라우저 음성 합성 발음
- 단어 저장 및 알고 있는 단어 표시
- 로컬 학습 기록을 이용한 초기 단어 추천
- PWA manifest 및 앱 파일 캐시

## 제한

YouTube 자막 자동 추출, 실제 재생목록 조회, 영상 제목 자동 조회는 구현하지 않았습니다. 샘플 제목과 자막은 데모용이며 실제 영상 자막이 아닙니다. 사전은 제한된 내장 어휘만 지원합니다. 개인화는 초기 규칙 기반 추천이며 검증된 실력 추정 모델은 아닙니다. 데이터는 브라우저 localStorage에 저장됩니다.

Android/iOS 실제 기기 설치 및 발음 동작은 아직 검증하지 않았습니다.
