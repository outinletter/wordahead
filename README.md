# WordAhead

영어 자막을 읽으며 단어 뜻과 발음을 확인하고 개인 단어장으로 복습하는 앱입니다. 한국어 안내를 사용하는 영어 학습자를 대상으로 합니다.

## 실행과 빌드
정적 HTTP 서버로 프로젝트 루트를 제공하거나 `ios/WordAhead.xcodeproj`를 Xcode에서 엽니다. iOS 빌드는 웹 파일과 256개 사전 shard를 Web 폴더에 포함합니다. Bundle ID: com.addvalue.wordahead. iOS 16 이상, iPhone 대상입니다. 서명 팀과 배포 설정은 실제 계정을 확인하세요.

## 기능
- 예시 자막 및 직접 입력한 영어 자막 읽기
- 단어 뜻, 음성 합성, 단어 저장·복습·삭제
- 알고 있는 어휘 체크와 JSON 백업·불러오기 (전체 데이터 백업 아님)
- 기기 내부 기록을 이용한 규칙 기반 추천, 읽기 위치·글자 크기 저장
- 전체 학습 데이터 삭제
- YouTube 영어 자막 요청: iOS는 기기에서 직접 요청, 웹은 Cloudflare Worker 사용
- Wiktionary 온라인 조회 및 Kaikki/Wiktextract 기반 내장 사전

## 제한과 제출
YouTube 자막 요청은 비공개 player 엔드포인트에 의존하므로 접근 제한·서비스 변경·지역에 따라 실패할 수 있습니다. 자동 수집을 항상 가능하다고 광고하지 마세요. 실패하면 직접 입력으로 학습할 수 있습니다. 영상 재생·재생목록 수집·회원가입·공개 공유·결제·외부 AI 기능은 없습니다. 예시 자막은 실제 영상 자막이 아닙니다.
